# Academic Collaboration, Productivity, and Biometric Attendance Management System

Final-year Computer Science project implementing a full-stack academic management platform with ESP32 + AS608 biometric attendance integration.

## Start Here

Before development, read:

1. [`PROJECT_SPEC.md`](./PROJECT_SPEC.md) — product, architecture, database, API, hardware, and implementation specification.
2. [`AGENTS.md`](./AGENTS.md) — repository rules for Codex and other coding agents.

## Repository Layout

```text
frontend/   React application
backend/    Node.js + Express + PostgreSQL API
docs/       Architecture, API, diagrams, and testing documentation
```

## Project Scope

Core areas:

- lecturer/student academic collaboration;
- course and enrolment management;
- assignments and deterministic task prioritization;
- announcements and real-time notifications;
- schedules and calendars;
- biometric attendance using ESP32 + AS608;
- attendance and task analytics.

Artificial Intelligence and Machine Learning are intentionally excluded from the implemented system.

## Development Order

Follow the implementation phases in `PROJECT_SPEC.md`, beginning with foundation, authentication, courses/enrolment, and assignments before hardware integration.
